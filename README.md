# 🚆 Train Ticket Booking System (Java)

A desktop-based Train Ticket Booking System developed in Java that allows users to book, cancel, and manage train tickets. Includes a secure admin panel for managing train schedules. Designed with a clean GUI and real-time database interaction.

---

## 📌 Features

- ✅ Book and cancel train tickets with ease  
- 🔄 Real-time updates for train schedules and seat availability  
- 🔐 Admin panel to add/remove/update trains  
- 💡 User-friendly GUI with modern FlatLaf styling  
- 🗃️ Secure and scalable cloud database integration  
- 🚫 Error handling and validations for smoother user experience  

---

## 🛠️ Tech Stack

- **Java (Core, AWT, Swing)** – for application logic and GUI  
- **FlatLaf** – for modern GUI look and feel  
- **NeonDB** – as the cloud database  
- **ProgressQL** – for connecting Java to the database  
- **IntelliJ IDEA** – used for development
